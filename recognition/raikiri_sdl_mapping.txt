# How it's derived (SDL2 src/joystick/darwin/SDL_iokitjoystick.c):
# - GUID: SDL's IOKit backend always uses bus type USB (0x0003), then
#   vendor, product and version, little-endian. Bytes 2-3 hold a CRC of the
#   device name (see below).
# - Buttons and axes are numbered after sorting by HID usage number:
#     buttons: Button 1..15 -> b0..b14, Consumer Record (Share) -> b15
#     axes:    X a0, Y a1, Z a2, Rz a3, Accelerator (0xC4, RT) a4, Brake (0xC5, LT) a5
#   so the Xbox layout's gaps (buttons 3, 6, 9, 10) show up as unused
#   b2, b5, b8, b9, the same as SDL's own Xbox Bluetooth mappings.
#
# Line 1 is the exact GUID SDL 2.32 reported on the Mac (name CRC 0xCCB3 in
# bytes 2-3). Lines 2-3 drop the CRC, and then the version, for SDL builds
# that compute it differently; SDL retries without them.
